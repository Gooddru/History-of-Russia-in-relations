# 📜 Исторический веб-сайт: Интерактивные доски по Истории России и Квиз ИТМО

Образовательный многостраничный веб-проект, созданный для интерактивного изучения ключевых периодов отечественной истории и истории науки. Проект включает в себя визуальные блок-схемы, таймлайны, подробные аналитические таблицы, проверочный интерактивный квиз и навигационный портал.

---

## 📂 Структура проекта

```text
history-boards/
├── index.html               # Главная страница-портал с навигацией
├── README.md                # Документация проекта
├── boards/                  # Папка с интерактивными досками и квизом
│   ├── decembrists.html     # Доска и сводная таблица: Общественные движения XIX века
│   ├── nevsky.html          # Инфографика и таймлайн: Князь Александр Невский
│   ├── romanovs.html        # Интерактивная доска: Династия Романовых (XVIII век)
│   └── itmo-quiz.html       # Интерактивный квиз: История и учёные Университета ИТМО
└── images/                  # Папка с локальными иллюстрациями и фонами
    ├── backgrounds/         # Фоновые баннеры для карточек главного меню
    ├── nevsky/              # Иллюстрации для доски Александра Невского
    └── romanovs/            # Портреты и материалы для доски Романовых
```

---

## Основные разделы и возможности

1. **Главный портал (`index.html`)**:
   * Стильный стартовый экран с фоновыми иллюстрациями.
   * Удобные карточки для быстрого перехода к любой исторической доске или проверочному квизу.

2. **Доска «Романовы» (`boards/romanovs.html`)**:
   * Музейный стиль оформления в теплых тонах пергамента.
   * Генеалогические связи правителей XVIII века и векторные стрелки переходов.
   * Разбор внешней политики монархов и текста Устава о наследовании престола 1722 года.

3. **Доска «Декабристы и общественные движения XIX века» (`boards/decembrists.html`)**:
   * Интерактивная блок-схема организаций (от декабристов до народников).
   * Возможность масштабирования, перетаскивания карточек и панорамирования холста.
   * Модальные окна с детальным разбором программ по пунктам (А–Г).
   * Встроенная интерактивная сводная таблица с функцией поиска по всем обществам.

4. **Доска «Александр Невский» (`boards/nevsky.html`)**:
   * Структурированная инфографика XIII века.
   * Сравнение западной и восточной политики князя.
   * Интерактивный таймлайн ключевых дат и сражений (Невская битва, Ледовое побоище).

5. **Квиз «История и учёные Университета ИТМО» (`boards/itmo-quiz.html`)**:
   * Интерактивная викторина из 5 вопросов по материалам лекции об истории вуза.
   * 3 вопроса, посвящённые выдающимся учёным ИТМО (В. Н. Чуриловский, С. Т. Цукерман, Ю. Н. Денисюк), и 2 вопроса по иллюстрациям и подписям из презентации лекции.
   * Автоматический подсчёт баллов, мгновенная проверка ответов, развёрнутые исторические пояснения (2–3 предложения) к каждому вопросу и режим быстрого показа всех ответов для проверки.

## 🛠️ Технологии

- **HTML5 / CSS3** (Flexbox, Grid, CSS Variables, Backdrop Filter).
- **JavaScript (Vanilla)** (Интерактивное управление состоянием, логика квиза и подсчёта очков, фильтрация таблиц, динамическое рисование связей).
- **SVG** для векторных стрелок и схем.
