# 📊 Работы по курсу «Россия в истории современных международных отношений»

**Университет ИТМО, 2 курс, 3 семестр**  
*Лектор: Богомазов Николай Иванович*

## О проекте

Учебный веб-проект с интерактивными материалами по истории России. Страницы объединяют хронологические схемы, инфографику, сравнительные таблицы и проверочный квиз. Проект предназначен для повторения лекционного материала и самостоятельной работы с ключевыми историческими сюжетами.

## Разделы проекта

### Главная страница

[Открыть портал](index.html) с навигацией по всем материалам проекта.

### Исторические доски

- [Романовы в XVIII веке](pages/boards/romanovs.html) — династические связи, внешняя политика монархов и Устав о наследовании престола 1722 года.
- [Александр Невский](pages/boards/nevsky.html) — инфографика XIII века, сравнение западного и восточного направлений политики, ключевые даты и сражения.
- [Общественные движения XIX века](pages/boards/decembrists.html) — развитие общественных организаций от декабристов до народников, их программы и сравнительная таблица.

### Проверочный квиз

[Квиз об истории и учёных ИТМО](pages/quizzes/itmo.html) содержит 5 вопросов, автоматическую проверку ответов, подсчёт баллов и исторические пояснения.

## Запуск

Проект не требует сборки и установки зависимостей. Откройте [index.html](index.html) в браузере или запустите любой локальный статический сервер из корневой папки проекта.

## Технологии

- HTML5 и CSS3: Flexbox, Grid, CSS-переменные и адаптивная вёрстка.
- Vanilla JavaScript: интерактивные доски, фильтрация таблиц, навигация и логика квиза.
- SVG: связи и схемы на исторических досках.
